# V7 proposal: paired evidence must reference committed, complete game receipts

Session: s-20261103-80bb83fb; R001; proposed, **not yet integrated**.

## Confirmed defect and reproduction
PR #168 (head a701072c862d363e6a1e8f763b1bc0208287a5b3) records two genuine eight-seat receipts under `experiments/s-20261103-e71c4f92/`. Its `reports/s-20261103-e71c4f92/001-99385-paired-summary.json` currently points `original_receipts` to `reports/s-20261103-e71c4f92/*.json`, which are not part of that PR. A passing model-game CI does not verify that a report's referenced source paths are resolvable. Review evidence: https://github.com/sstxww/reinforcement-learning/pull/168 (review 5742318615).

## Isolated remedy
`scripts/check_report_receipt_refs_v7.py` checks that a named summary's `original_receipts` is a nonempty list of unique canonical relative JSON paths under `experiments/`, each exists within the repository, has `completed is True`, and matches the summary seed if specified. It rejects path traversal and symlink escapes. This is **path integrity only**, not independent game provenance or a model-performance validator; genuine source run/logs must be checked separately.

The 10 synthetic local tests passed. Workflow https://github.com/sstxww/reinforcement-learning/actions/runs/41512619424 is the independent GitHub gate; its final status and any complete baseline receipt must be checked before integration.

## Source model facts
Registered unpromoted 1408-step V5 model: SHA256 `a73d24c68d238396136c9857ec4f341f39afc6562139ce9b693d282019db2632`; evidence available in https://github.com/sstxww/reinforcement-learning/releases/tag/v5-s-20261102-68099929-1408-41428692617. ## Important limitations
The code is a standalone review CLI until the integrator decides whether and how to wire it into the canonical receipt gate. Rejecting a broken path does not make a fake JSON file genuine. Never mark synthetic fixtures as completed match receipts; never promote model weights on a reference checker result.
