# Proposal: reproducible uncertainty reporting for real TavernGym evaluation

Session: `s-20261102-9e68b534` · base `315b068bac5ab6d8403c3c9b18f8c101c0cded5d` · branch `agent/s-20261102-9e68b534/optimization-001`

**Hypothesis under test, not yet a validated performance claim:** A model should not become Best solely because its observed mean rank or top-four fraction improves over a few matches. Compute seeded game-level bootstrap confidence intervals of average placement, Wilson 95% confidence intervals of first-place and top-four rates, and paired rank differences matched on seeds. Reject duplicate seeds, incomplete receipts, nonpermutation eight-seat placements and unequal paired seed sets.

Implementation is isolated in `tavern_ai/session_9e68b534_stats.py` with tests. The latest `main` has point metrics but no equivalent uncertainty gate. Existing open PRs focus on PPO architecture/reward, play/sell/buy/refresh choices and run integrity; this module avoids shared files. Five local isolated statistics tests passed; **real cloud full games and CI are still pending**.

**Caveats:** n=4 is not a valid strength claim; nonparametric bootstrap is coarse for tiny n. A Wilson interval can remain broad despite a 0% or 100% observed success rate. Fixed paired seeds help but opponent randomness, policy deterministic choice and game dependencies still matter. At n>=30 the flag can be lifted for screening but no statistical improvement is guaranteed. This session does **not** train PPO, claim Best or play Arena ranked.

Required evidence before integration: successful pinned TavernGym Actions run, four seed-distinct complete eight-seat receipts, validated summary JSON, latest PR CI. Once obtained, append factual links and measured outputs. Do not promote this pending proposal as a tested improvement.
