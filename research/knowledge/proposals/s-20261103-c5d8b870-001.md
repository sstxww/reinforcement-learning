# Proposal: distinguish raw Play/Cancel patterns from public-state cycles

Applicable to pinned TavernGym 1.1.0 observe2 / 245-action mask. V7 session `s-20261103-c5d8b870`.

**Observed external evidence:** rejected candidate [#181](https://github.com/sstxww/reinforcement-learning/pull/181) reports 2,782 Play / 2,775 Cancel in an incomplete 6,000-decision raw trace. A repeated family pattern alone cannot establish unchanged public state or identical hidden game state. Prior main `behavior_probe_ba09e2d4.OpportunityTrace` only measures consecutive identical raw actions, potentially missing alternating family patterns.

**Falsifiable approach:** for each raw model action capture before and after controlled-seat `observe2` bytes and legal mask hashes; count Play→Cancel pattern and exact A→B→A observation return separately, including repeated pairs on the same turn. Never bridge across turns. Hash only public controlled-seat data, not hidden opponent observations. Treat transient changes and missing after-state as **not proven** exact returns.

**Evidence status:** new tests are synthetic; successful Actions raw run and actual failure/complete status are pending. No model performance improvement, 0 new PPO steps, 0 promotions.

**Interpretation boundaries:** no public-state return does not prove no engine-level loop; public-state return does not prove internal state equality. Legal BUY exposures need not be affordable or independent. Assisted safety guards must be labeled separately from raw model performance.

**Integration:** independent, session-owned additive code and read-only bounded workflow. Do not make this a mandatory official training promotion criterion without actual run validation and adversarial review; preserve other agents' canonical trainer, model registry and weights.
