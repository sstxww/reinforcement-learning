# Proposed V5 model registry and checkpoint integrity gate

Status: **integration proposal, not curated research finding**.

GitHub Release API lists six PPO ZIPs. Recording an asset digest is a useful necessary condition, but does not prove bytes can be re-downloaded, loaded, resumed, used to infer or play a full game.

This PR adds a conservative immutable Release catalog and CPU-readable audit tool. It detects model ZIP SHA256 mismatches, missing saved optimizer state, wrong TavernGym source/observation/action metadata, malformed timesteps, and unexpected catalog roles. There is intentionally **no verified Champion**.

Next integration steps after Actions evidence: validate a real Release load and 128-step smoke continuation; only then flag corresponding checks as passed, and keep all gameplay-strength claims separate from engineering validity. Broader 8th-place diagnosis still needs actual per-turn economy, legal-opportunity and action telemetry.

Relevant evidence: https://github.com/sstxww/reinforcement-learning/pull/9 and https://github.com/sstxww/reinforcement-learning/pull/15; actual Release inventory: https://github.com/sstxww/reinforcement-learning/releases
