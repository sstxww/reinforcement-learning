# Proposal s-20261102-e046f72e-001 — Smaller extractor and mandatory bounded model actions

**Status: candidate research finding; not an integrated or validated win-rate improvement.**

## Hypotheses and evidence

- TavernGym pinned **1.1.0**, engine hash `6d8712c93022ba11`,
  observe2 4017 float / 447 card / 245 masked actions, card vocabulary 3984.
- Three independent GitHub Actions executions (two failed *post-training*,
  one fully succeeded) used original vs compact MaskablePPO, each 128
  true training steps, seed `261102`. Final run `41414170876`
  completed both genuine eight-seat matches on seed `26110201`.
- The compact extractor is a drop-in observation representation requiring
  833,014 model-policy parameters vs 1,449,846 for original:
  **42.5447% fewer, objectively verified**.
- Measured `model.learn` times (original vs compact seconds):
  `0.315/0.225`, `0.159/0.105`, `0.268/0.200`.
  All are control-first; systematic warm-up/order bias is plausible.
  Treat faster learning as **preliminary**, not established.
- Original and compact match rank: **8/8 and 8/8**, n=1 each;
  candidate 518 decisions, 6 legal forced-end-turns; control 95
  decisions, 0 interventions; no invalid actions or truncated combats.
  **No competitive improvement detected or statistically inferable**.

## Failure evidence

- [Run 41413064111](https://github.com/sstxww/reinforcement-learning/actions/runs/41413064111):
  model playing original canary did not finish before game-loop cap.
  A model that can repeatedly choose legal non-terminating actions is not
  guaranteed to complete a match merely because all actions are legal.
- [Run 41413715344](https://github.com/sstxww/reinforcement-learning/actions/runs/41413715344):
  isolated canary CLI initially rejected `--policy model`.
- [Successful run 41414170876](https://github.com/sstxww/reinforcement-learning/actions/runs/41414170876):
  compatibility fixed, and session-owned masked end-turn cap of 80
  actions per turn yielded two actual complete games and model artifacts.

## Recommendations for integration

1. Consider compact extraction as a memory/compute ablation, not an
   immediate replacement for a battle-tested architecture.
2. Keep a legal-mask-checked **maximum action count per turn** for model
   evaluation and deployment, and log interventions as an extra quality metric.
3. Run randomized AB/BA timing with multiple seeds and warm-up exclusion.
   Estimate timing distribution, not one percentage.
4. Compare >=20 held-out independent eight-seat games per variant,
   using paired seeds, placement, top-four/first rates and uncertainty
   intervals. Short-trained models both finishing 8th is insufficient.
5. Store checkpoints durably before claiming models are preserved; current
   [artifact](https://github.com/sstxww/reinforcement-learning/actions/runs/41414170876/artifacts/13127575014)
   expires 2027-01-01T08:38:46Z.
