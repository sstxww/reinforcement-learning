# s-20261102-2acfa761 R001: paired receipts should not silently mix guard-assisted PPO with raw PPO

Main's basic `tavern_ai/evaluate.py` summarizes ranks but does not retain detailed provenance across already-recorded independent evaluation receipts. This proposal adds an **offline, additive** gate that rejects duplicated or unmatched seeds, invalid eight-seat completion, wrong TavernGym fingerprint, mixed weight hashes and invalid policies. It declares guarded candidates as assisted, keeps paired rank deltas, provides an exploratory per-game bootstrap interval and **never auto-promotes** a model.

In the existing registry (observed 2026-11-02), the experimental latest checkpoint has 1,408 steps with heldout ranks [8,8,8] and no Champion. Distinct draft PR #103 documents legal buying opportunities (521 seat decisions) with zero buys for guarded V2 across three seeds: strong behavior diagnosis lead, but it doesn't isolate learning objective, model architecture, or a causal fix. Integrate distinct evidence without merging redundant workflows or policy variants.

The proposed code has pure test fixtures only; independent complete TavernGym receipt will be generated by the branch-only GitHub workflow and must be checked before this PR becomes merge eligible.
