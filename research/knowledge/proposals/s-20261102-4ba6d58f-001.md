# Proposal — Release-indexed checkpoint integrity before new PPO training

Persistent GitHub Release assets exist, but a digest shown by the asset API, a verified downloaded SHA256, a successful MaskablePPO.load, true optimizer-state continuation, and a model-controlled full eight-seat game are not equivalent. Keep distinct verification flags and permit no automatic Champion or Latest resumable registration without all applicable gates.

The inventory records 6 existing versioned releases, including V2 1280-step model with no demonstrated improvement against old model on four heldout seeds (PR #15). Do not promote V2 or blindly repeat PPO training.

Project evidence: https://github.com/sstxww/reinforcement-learning/pull/15 ; https://github.com/sstxww/reinforcement-learning/pull/60.
