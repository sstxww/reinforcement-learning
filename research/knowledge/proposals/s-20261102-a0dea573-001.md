# V5 integration proposal: explicit Champion evidence gate

Author/session: `s-20261102-a0dea573`. This is a **proposal**, not curator-approved knowledge.

## Confirmed code gap
`tavern_ai/model_registry.py` currently validates the string `review_status=verified` for a Champion but did not demand independently attested saved-weight/hash, CPU-load, optimizer-resume, actual completed game, and competitive gain fields. This made premature *declared* Champion promotion possible despite incomplete validation.

## Parallel ownership correction
A stronger Champion gate covering the same gap already exists in draft PR #138, so the overlapping Champion changes on this branch were withdrawn. This proposal is only a cross-reference, not a competing Champion implementation.

## Proposed narrow repair
The remaining unique patch validates `population`/`rejected` IDs against the immutable registry, forbids duplicates and unknown entries. Reuse PR #138 for Champion evidence instead of merging overlapping gate logic. Keep Champion null until a reviewer checks primary Actions/Release/receipt evidence independently.

## Negative experimental evidence (not causal proof)
Reported V2 paired [8,8,8,8] vs V1 [8,8,8,8] (n=4); published 1408-step candidate heldout [8,8,8] (n=3). Additional PPO steps did not establish improved placements. Need model-only raw action/BUY-legal opportunities, economic state and first-divergence stage before changing reward or training budget.

## Decision
Integration-first; no Champion promotion, no broad PPO training, no ranked play. CI and real-game receipt are mandatory before merge.
