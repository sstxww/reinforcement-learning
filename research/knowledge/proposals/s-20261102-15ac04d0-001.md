## Own narrowly scoped P1 change

New standalone \`tavern_ai/paired_receipt_gate_v5.py\` compares real eight-seat game receipts only when:
- both arms have exactly the same (seed, controlled-seat) keys with no duplicates;
- both arms pass pinned TavernGym 1.1.0/engine hash/permutation/completion and no-truncation checks;
- candidate uses one consistent SHA256-identified model;
- observed guard/fallback counts are disclosed; guarded results remain diagnostic only;
- paired mean rank difference (candidate minus baseline, negative favors candidate) and deterministic paired-bootstrap interval are reported;
- n<5 leaves an interval unavailable; statistical signals cannot auto-promote a Champion.

This complements, rather than edits, existing \`tavern_ai.evaluate\`, \`seat_rotation\`, and canonical registry. No production model, shared train.yml, or other Agent paths are changed. Synthetic unit tests do not count as matches.
