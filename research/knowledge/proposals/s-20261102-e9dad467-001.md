# Proposed finding s-20261102-e9dad467-001 (pending verification)

## Hypothesis
Current baseline and many PPO demonstrations control only seat 0. Varying the controlled seat across real eight-player TavernGym games could reveal sensitivity that seat-0-only measurements miss.

## Scope
Adds a distinct evaluation instrument, not a stronger policy and not changes to shared training workflows. Each controlled seat uses the existing deterministic baseline; other seven use official TavernGym bots.

## Planned evidence
2 seeds × 3 seats, actual complete matches and source-hashed receipts via the session-specific Actions job. No observed effect claimed until artifacts exist.

## Validity limits
The seat swap also changes hero assignment and possible random-number consumption, so placement differences are descriptive, not a proof of intrinsic engine bias or stronger decisions. Six games are too few to support promotion decisions.

## Reusable practice
For later comparative evaluation, report controlled seat explicitly and index placements by that seat, not always placements[0]. Preserve engine version, seed, source hash, legal action validation and actual game completion.
