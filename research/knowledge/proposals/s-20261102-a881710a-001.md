# Proposal 001 — game-engine-backed static knowledge, with evidence levels

Session `s-20261102-a881710a`, validated by own successful GitHub Actions run 41421685972; final PR CI pending.

**New hypothesis:** metadata extracted from the pinned engine avoids guessing what each card does, and makes 245-action decoding and card-vocabulary drift observable before training. In the proposed extractor, every card gets an embedding index, card ID, localized names, kind, tier, stats, races, printed keywords, printed mechanics and static pool flags; no guessed effect text is added.

**Evidence levels:** `engine_static` for compiler-provided metadata; `engine_observed` for legal masks and completed simulated decisions; `effect_script_verified` remains false until a card-specific trigger test; `competitive_strength` is not evaluated.

**Current limitation:** emitted artifact is an engine-bound metadata dataset. It cannot by itself establish buying priority, combat synergies or higher average placement. No training weights generated in this round.

Upstream: `MCG-NJU/AutoTavern@fb61201a557ddd36a411cf44aac51ce4d9b606ce`, `crates/taverngym-py/src/lib.rs`, `crates/taverngym/src/types.rs`, `crates/taverngym/src/actions.rs`.

**Decision:** do not add static labels as ground-truth behavior targets until simulator-backed trigger tests exist; do not promote a model based on this PR alone.
