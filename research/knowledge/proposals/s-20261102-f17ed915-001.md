# V5 evaluation evidence gate proposal — s-20261102-f17ed915

Main already stores real TavernGym eight-seat receipts and a model registry, but simple historical rank comparison can mix seeds, source commits or model weights; old schema-1 receipts do not always disclose explicit safety fallback counters.

This PR proposes a read-only, conservative paired audit script and fail-closed tests. Use it **before** accepting performance claims from completed-game receipts. It consumes existing main seeds 99125–99127 and computes comparable results without touching policy or checkpoints.

Confirmed from main receipts: 1,408-step unpromoted candidate [8,8,8], matched baseline [6,8,8], mean rank disadvantage +0.667 over only three seat0 pairs. Confirmed from main behavioral report seed 99128: 35 decisions where BUY was legal and no BUY chosen. These are observed symptoms, not an established root cause or strong rank inference. Do not expand PPO merely because the model has more steps.

This report tool does **not** claim raw/fallback-free policy on old receipt schemas, new training, new weight archival, or model promotion. A larger seat-rotated independent evaluation is still required, and future receipts should include explicit fallback/illegal-action counters.

Engineering prerequisite: own isolated workflow full-game CI and final-head review. Work is intended for integration without collisions with checkpoint and behavior-probe PRs.
