Scope: GitHub PR metadata and GitHub Actions exact-head verification; applicable to PRs targeting `sstxww/reinforcement-learning:main`.

**Evidence-backed risk:** #165's prior CI was attached to an older branch HEAD; #173/#177/#172 overlap assisted-evidence counter handling. During this session main moved from `3a745c6` to `990acd21`. Therefore a historical green run cannot establish current PR safety.

**Proposed reusable tool:** `scripts/v7_pr_head_audit.py --pr N --expected-head-sha <40hex> --expected-main-sha <40hex>`. Always read-only; stale refs, Draft, unknown mergeability and no successful same-HEAD `tests-and-full-match` check block. Positive output is **only** `needs_integrator_review` and `merge_authorized=false`.

**NOT proof of:** genuine game provenance, independent review, code security, optimizer restoration, branch rules, valid exclusive CAS/queue lease, current merge result CI, or model performance. These must still be checked before a real merge.

**Counterevidence / future improvement:** GitHub pull_request tests may attach to synthetic merge SHA; HEAD-only lookup can conservatively fail legitimate PRs. Never weaken the check to accept arbitrary previous-head success. Add explicit verified current merge-result matching in a later small reviewed change.
