# V5 R001 proposed knowledge: distinguish legal purchases from ignored purchases

Status: PROPOSED, not yet validated in main; read source receipts and CI before curating.

A repeated rank-8 outcome is not a diagnosis. A real action audit in open draft PR #60 reports zero Buy actions over three low-LR model games, but does not count the number of states in which Buy was legal. The existing 1,280-step V2 model in a durable Release also ranked 8 across four historical heldout games. We cannot infer the same behavior from rank alone.

Add a session-isolated full TavernGym study comparing the V2 Release against the unchanged BaselinePolicy on the same new seeds and seat. Always collect the full legal mask and pre-action state, action family, chosen action, explicit forced-guard counts and own-seat gold/board snapshots. Report whether Buy was legal at all, whether END_TURN was selected while Buy remained legal, and whether the guard rather than model made a decision.

Hypotheses to falsify separately:
1. V2 model rarely buys despite masked-legal Buy opportunities.
2. V2 buys but wastes gold or fails to play purchased cards.
3. Model stalls in optional actions and only guard finishes matches.
4. Much of the observed rank-8 result comes from seat, hero or seed mix rather than a single learned action collapse.

Run new heldout seeds, verify Release hash and actual full games, preserve per-match receipts. If data supports any hypothesis, test one targeted correction; do not immediately claim more PPO steps will help. No champion/model promotion without fair independent paired evaluation and checkpoint recovery gate.

This is an integration proposal, not a verified result. The CI/workflow, if successful, will produce the authoritative measurements.
