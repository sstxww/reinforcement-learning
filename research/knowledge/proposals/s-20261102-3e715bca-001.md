## Observed gap
The mainline `tavern_ai/train.py` previously used `prev["engine"] == verify_engine()` alone before `MaskablePPO.load`, although stronger `tavern_ai.checkpoint_preflight.audit_archive` already existed. A damaged or structurally optimizerless model could reach deserialization without a front-door fail-closed integrity check. Newly generated metadata lacked a stored checkpoint SHA; independently trusted SHA was not accepted by the CLI.

## Minimal corrective integration
Reuse the existing audit rather than add another registry or trainer: verify metadata/ZIP CRC/optimizer, honor externally supplied expected SHA, check loaded timesteps against metadata and write SHA to newly saved metadata. Legacy absence of external SHA remains a weaker structural verification path; do **not** conflate it with trusted Release provenance. Unit tests contain only synthetic ZIPs.
