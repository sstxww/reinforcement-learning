Six true full games reached Game.is_over(). Candidate rank outcomes 8, 7, 5; n=3, mean rank 6.667, first place 0%, top-four 0%; 127/127 seat-0 choices mask-legal; 0 exact repeated public-observation+mask signatures within turns. No illegal actions or simulator truncations. Unit tests, real engine install and match/receipt assertions passed in the isolated run.

## Reusable engineering technique
Hash observe2 float bytes + card-index bytes + legal_mask bytes with the turn to detect recurrence of exactly identical *observable* decision states. Record legal-action counts, action-ID buckets, decisions per turn, and a per-seed baseline replay-parity check. Use this as diagnosis, not a proxy for win rate or hidden-state equivalence.

## What did NOT work / what this cannot establish
No PPO training (0 steps); no checkpoint; no new strategy; no demonstration that trained PPO behaves similarly. No gameplay improvement can be inferred; baseline actually placed 8th, 7th and 5th in the tiny sample. Zero recurrence for baseline does not rule out loop pathologies for a different model. Do not promote model Best status. The 30-day run Artifact is not a permanent checkpoint; small actual receipts and metrics are committed to the session branch.
