# P1 proposal: pair integrity and guard separation before PPO expansion

## Motivation grounded in main + open PR evidence
The shared \`tavern_ai.evaluate\` compares mean ranks on fixed seat 0, but does not reject duplicated/mismatched seed-seat comparisons or distinguish raw PPO from guarded inference. In existing V2 real eight-player samples, legal Buy opportunities can exist with zero model purchases; a 46-buy forced override still produced 8th place. More timesteps or guard rules alone are therefore insufficient evidence for promotion.

## Isolated, opt-in implementation
- \`tavern_ai/paired_evidence_s_5ce8a1d4.py\` compares actual canonical receipts at explicit matched seed and seat; validates engine, completion, eight placements, no turn-limit end/truncated combat, model checkpoint SHA256.
- Raw and guarded modes are separate. Guarded comparisons require per-game fallback counts. Counts are *caller-supplied* and should be machine-attested by later instrumentation; this tool refuses to conflate the two modes.
- Reports mean rank, top-four/first rate, signed paired delta, individual paired rows, and a descriptive reproducible paired bootstrap only with >=10 pairs; small n reports null CI. It never promotes Champion.
- Isolated GitHub Action performs a real same-policy negative control with two real complete eight-seat matches and permanent session receipts if successful. Baseline replay is not new PPO training or a model improvement.

## Integration/next research
After independent CI+receipt review, reuse the validator from a single common evaluation entrypoint (integration owner review required) and add real model behavior telemetry, decision-stage legal Buy opportunity counts, and strict fallback provenance. Run multiple independent held-out seeds and seat rotations. Only train further once correctness and resumable checkpoint gates are met.

**No strength promotion, no Arena match, no new model checkpoint in this proposal.**
