# Proposal s-20261102-5d71c0ab-001 — Prevent evidence-free Champion promotion

## Grounded problem
The integrated Release catalog `models/release_inventory_v5.json` deliberately contains no verified Champion. The existing `model_registry.read_registry` enforces only the `review_status` string when selecting a Champion, leaving it possible to set this label without mandatory independent evidence.

## Proposed fix
Require strict boolean `true` for durable download, SHA256, CPU load, optimizer resume, complete real eight-seat match and competitive gain before a registry can designate Champion. Also reject nonexistent or duplicate population/rejected model references. This is a validation gate, **not** evidence that any present model is strong.

## Reproducibility
Tests in `tests/test_model_registry_champion_5d71c0ab.py` use synthetic entries only. Real-game and 1408-step Release diagnostics are performed separately in bounded workflow `.github/workflows/v5-registry-s-20261102-5d71c0ab.yml`. All false/equivocal findings must remain unpromoted.
