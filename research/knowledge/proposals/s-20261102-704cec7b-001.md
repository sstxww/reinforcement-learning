# Proposal: integrity-first model reuse, followed by legal-opportunity diagnosis

**Status:** engineering changes under independent CI; model strength **not** established.

Evidence from existing verified work:
- PR #43 (now merged): true seat-rotated Baseline matches, 6/6 complete, mean placement 7.67. Small samples exclude competitive promotion, not instrumentation integration.
- PR #8: historical Release inventory and model storage caveats; its draft conflicts with main and is not suitable for wholesale merge.
- PR #9 and #15: 256→1280 actual PPO steps, durable Releases, but no measured gain; last four tracked V2 model ranks all eighth.
- PR #60 (dependent on #51): 1e-4 arm zero BUY / 21 chosen END_TURN across 3 real games; 3e-4 arm 788 'other' actions / 21 guard ends; both noncompetitive. Missing action-availability and observation-delta evidence prevents claiming the mechanism has been causally isolated.

Preserve known weights with hashes in a lightweight registry that rejects corruption and mismatched parent steps. Verify V2's Release SHA, SB3 load and independent 128-step resume. Do not use a transient GitHub Artifact as the only durable copy. Keep `champion=null` until a model completes full unguarded games and independent paired evaluation supports an actual gain.

For P2, gather per-decision legally available buys, selected action category, board and economy context, repeated action IDs and pre/post observable changes on fresh seeds. Report raw, guarded and baseline outcomes separately. Do not multiply training steps to compensate for an unmeasured END_TURN pathology.

No original weight files, large rollouts, synthetic receipts, or ranked Arena access belong in this proposal.
