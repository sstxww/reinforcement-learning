# Proposed integration: prevent silent reset of the main PPO model

Observed main workflow `train.yml` loads the last success Artifact and, if its download fails or files are missing, silently starts from scratch. Artifacts are expiring, so a scheduled run can lose cumulative training continuity.

Proposed safe behavior: fail closed on absent previous Artifact; require operator's explicit manual `fresh_start=true` **only where no previous successful main run exists**, and preflight the ZIP, PPO optimizer-state member, metadata and pinned engine fingerprint. An accompanied metadata checksum is not an externally trusted digest.

Remaining work: implement a separately reviewed, explicit Release-source selection with published SHA256 verification and actual optimizer continuation proof. The canonical registry's experimental `latest` (1408 steps; heldout ranks 8,8,8) must not silently become `Champion` or the official training seed.

Independent behavioral evidence from PR #103 (521 masked-legal BUY opportunities with zero BUY over three guarded V2 games) suggests investigating the learned action policy and repeated actions before funding larger PPO runs; does not establish a unique causal fix.
