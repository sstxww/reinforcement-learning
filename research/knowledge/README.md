- 会话原始研究日志：[`research/sessions/`](../sessions/)
- 待审核的经验建议：[`research/knowledge/proposals/`](proposals/)
- 并发隔离规则：[`docs/SESSION_PROTOCOL.md`](../../docs/SESSION_PROTOCOL.md)

集成者合并通过的经验后在此建立主题条目（如 `strategy.md`、`training.md`、`failure-cases.md`），每条结论写清来源 PR、样本量、适用版本和反例，不以单局结果宣称优势。
