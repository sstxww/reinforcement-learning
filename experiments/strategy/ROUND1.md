# Strategy / round 1

Hypothesis: prioritizing buying before optional positioning and bounding per-turn actions improves reliability and tempo. The candidate branch implementation defaults to a 36-action limit, while preserving mandatory choices and play-before-buy behavior.

This is an unverified candidate strategy change, not a performance claim. The two GitHub Actions workflows on this branch are configured to produce genuine TavernGym receipts and one paired baseline comparison; their execution status and recorded artifacts are authoritative.

No receipt is claimed in this document. Do not infer statistical improvement from a single seed. Independent multi-seed comparisons remain required.
